## Host-side test stubs

`ports/stm32g0/flash/hal_stub/` and `ports/c2000/f28004x_direct/hal_stub/` contain **re-implementations written for this project** of
the small subset of the ST HAL / TI Flash API that the ports call, so the port logic can run on a PC. They are not copies of vendor
code and must not be used on a target.
