# Known Open Issues

This file is an English translation of the maintainer's table of known open issues for the firmware update driver. Each row describes a limitation, an unverified assumption, a pending decision or a measurement still to be done.

Source code comments refer to these rows as "open issue N". The numbers are kept exactly as in the original table, so row numbers are stable identifiers and are not necessarily contiguous with the order in which the items were raised. Rows are sorted by number.

Conventions:

- **[UNVERIFIED]** marks a statement or number that has not been confirmed (against a reference manual, data sheet, standard or real hardware) and needs confirmation.
- `G<n>` and `D<n>` (e.g. G11, D41) are internal task and design-decision identifiers from the original project log.
- The **Status (original)** column reproduces the status as written in the original table. It may be out of date.
- The **Repository note** column is filled only where the current repository content confirms that an item is outdated or resolved. An empty cell means "not checked or not confirmed", not "still open".
- Identifiers mentioned in entries that do not exist in this repository's code (`fwu_port_crypto`, `fwu_verify_image_step`, `flash_ecc_recover`) are names from the maintainer's notes, proposals, or code outside this repository. The crypto port interface that exists here is `fwu_crypto_t` in `src/crypto/fwu_crypto.h`; no stepwise verification function exists.
- Paths follow the current layout: modules under `src/<module>/`, platform ports under `ports/`, examples under `examples/`.
